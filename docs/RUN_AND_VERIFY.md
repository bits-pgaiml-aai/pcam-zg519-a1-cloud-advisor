# Run and verify

1. Create venv and install `requirements.txt`.
2. Start Ollama and pull the model used in README.
3. `streamlit run app.py`
4. Select scenario A, B, C, then D; click **Run all agents**.
5. Confirm all six agents appear (or five if LLM unchecked).
6. Record a Learning Agent outcome and re-run to see updated rates.
7. Save screenshots under `screenshots/` and JSON under `evidence/`.
